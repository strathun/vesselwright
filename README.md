# Vesselwright

A game about preparation. Wire stones into a socket lattice, discover how every combination composes, then take your Vessel into the Undercroft to test it in freeze-time combat.

**Play:** https://strathun.github.io/vesselwright/

On iPhone, open it in Safari, then Share → Add to Home Screen. It runs full-screen and works offline. Sign in on the Save tab to keep one save across devices.

- `DESIGN.md`: how the systems work, and the rules they follow
- `CLAUDE.md`: how the code is organised and how to work on it
- `node tools/check.mjs`: compiles every rite combination and checks the project
